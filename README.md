# YT Downloader

Десктопное приложение для скачивания видео, аудио и целых плейлистов с YouTube.
Tauri (Rust) + React + Tailwind CSS. Скачивание выполняет `yt-dlp`, конвертацию/слияние — `ffmpeg`.

## Возможности

- Ссылка на видео, аудио или плейлист — приложение само определяет тип и подтягивает метаданные
- Выбор качества видео (до 4K, если доступно) и аудио (mp3/m4a/opus/flac/wav, битрейт)
- Точечный выбор видео из плейлиста, переопределение формата для отдельных роликов
- Опционально: сохранение плейлиста в отдельную подпапку по названию
- Очередь загрузок с прогрессом, паузой/докачкой, автоповтором при сбоях
- Встроенные `yt-dlp`/`ffmpeg`/`ffprobe` — не требует установки зависимостей отдельно
- Тёмная/светлая тема, русский и английский интерфейс

## Разработка

Требуется Node.js 20+, Rust (через [rustup](https://rustup.rs)).

```bash
npm install
npm run tauri dev
```

## Сборка

```bash
npm run tauri build
```

Готовый `.app`/`.dmg` появится в `src-tauri/target/release/bundle/`.
Бинарники `yt-dlp`/`ffmpeg`/`ffprobe` в `src-tauri/binaries/` не хранятся в репозитории — их
подготавливает CI (см. `.github/workflows/release.yml`) либо нужно положить туда вручную
перед локальной сборкой (при их отсутствии приложение в dev-режиме откатывается на системные
версии из `PATH`/Homebrew).
